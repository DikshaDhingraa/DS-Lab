# Lab Assignment 4: Queues (UCS301 Data Structures)

| File | Problem |
|---|---|
| `1_simple_queue.cpp` | Q1 – Menu driven simple queue (enqueue, dequeue, isEmpty, isFull, display, peek) |
| `2_circular_queue.cpp` | Q2 – Menu driven circular queue (same operations) |
| `3_interleave_queue.cpp` | Q3 – Interleave first half of queue with second half |
| `4_first_non_repeating.cpp` | Q4 – First non-repeating character in a stream, using a queue |
| `5_stack_using_queues.cpp` | Q5 – Stack implemented using (a) two queues and (b) one queue |
| `6_generate_binary_numbers.cpp` | Additional Q1 – Generate binary numbers 1 to n using a queue |
| `7_sort_queue_no_extra_space.cpp` | Additional Q2 – Sort a queue without extra space |
| `8_sort_queue_using_stack.cpp` | Additional Q3 – Check if a queue can be sorted into another queue using a stack |
| `9_sandwich_students.cpp` | Additional Q4 – Number of students unable to eat lunch |

All programs are written in C++ and compile with:
```
g++ -std=c++17 filename.cpp -o output
./output
```
